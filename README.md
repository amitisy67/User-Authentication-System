# 🔐 User Authentication System 🐍

## 📌 About The Project

A simple Python user authentication system that allows users to create accounts and stores their information securely. The project includes user registration, password validation, and an admin system for managing users.

## ✨ Features

* 👤 User registration
* 🔑 Password length validation
* 🚫 Prevents duplicate usernames
* 🔐 Password hashing using SHA-256
* 👑 Admin access with key verification
* 💾 Saves user data using JSON

## 🛠 Technologies Used

* Python 🐍
* JSON
* hashlib
* Object-Oriented Programming (OOP)

## 🚀 How To Run

1. Clone the repository:

```bash
git clone https://github.com/yourusername/User-Authentication-System.git
```

2. Open the project folder:

```bash
cd User-Authentication-System
```

3. Run the program:

```bash
python main.py
```
